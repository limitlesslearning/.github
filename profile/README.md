# Limitless Learning

**Free for learners. Open source. Built around mastery.**

Limitless Learning is a global knowledge graph that maps concepts as mastery nodes with explicit prerequisites — not siloed courses. Learners advance when they prove competency, earn verifiable credentials, and connect those credentials to real jobs.

## What we believe

- **Free for learners forever** — core learning, assessments, progression, and credentials stay free. Revenue comes from companies and partners, never from learners.
- **Mastery over pedigree** — advance at a high competency threshold; no age gates, seat-time rules, or arbitrary deadlines.
- **One living map of knowledge** — every concept is a node with clear prerequisites across domains.
- **Proof that travels** — verifiable credentials linked to company-defined job profiles, skills-first.
- **Open and auditable** — open-source infrastructure and community review so the platform can evolve without stagnation.
